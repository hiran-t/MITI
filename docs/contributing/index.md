# Contributing

MITI welcomes contributions: bug reports and ideas in [Issues](https://github.com/hiran-t/MITI/issues) and [Discussions](https://github.com/hiran-t/MITI/discussions), and changes as pull requests. Start with [CONTRIBUTING.md](https://github.com/hiran-t/MITI/blob/main/CONTRIBUTING.md): how to set up a development copy, the checks to run and the coding style.
