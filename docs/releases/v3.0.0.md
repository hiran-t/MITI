# MITI v3.0.0 — MITI's own IDE-style look

MITI 3.0 drops the Foxglove look for a design of its own, modelled on VS Code and JetBrains. Every tool works exactly as in 2.2: panels, settings, topics, the 3D Scene and connection settings behave the same; only the interface around them has changed.

## Look

- **Neutral dark theme.** Gray surfaces and 1px dividers; no rounded cards or colored boxes.
- **Muted teal accent (`#2fb4c4`)** marks only what is active, selected or focused.
- **Status colors mean something.** Green, amber and red appear only for real state (connected, warnings, errors), so problems stand out.
- **The MITI cyan (`#15FBFF`)** stays in the logo and becomes the default color for paths, poses, camera frustums, TF lines and the publish tool in the 3D Scene.

## Workspace

- **Title bar**: the MITI logo, the layout name, and icon buttons for Reset layout and Add panel.
- **Activity bar** on the left, as in VS Code: Panel settings, Topics, Problems and Sources.
  - Click a view to open it in the sidebar; click the open view again to close the sidebar.
  - Up/Down arrow keys move between views; Escape closes the sidebar.
  - Problems shows a badge when the connection fails.
- **Status bar** at the bottom:
  - the connection box (address and state; the gear opens connection settings), teal when connected and red when disconnected
  - the problem count, the number of panels and the app version

## Panels

- Each panel header is a tab: icon, title and close button. Expand and lock sit on the right.
- The selected panel's tab has a teal top line.
- Panels are separated by 1px seams with square corners. Dragging, splitting, resizing, expanding and locking work as before.
- Topic list rows, the settings tree, the Log panel, the connection dialog, and the State Machine and Button Switch panels are restyled to match.

## Removed

- **Camera panel presets.** The Color, Detection, Depth and IR quick-pick buttons are gone; choose the topic in the Image Topic field. New camera panels still start on `/camera/color/image_raw`.

## For developers

- UI colors live in one place, `src/lib/theme.ts`. They are emitted as `--miti-*` CSS variables and exposed as Tailwind colors: `accent`, `ok`, `warn`, `danger` and `surface-*`. The `gray-*` scale is remapped to the new neutrals.
- `src/app/globals.css` contains no hard-coded colors.
- The app version shown in the status bar comes from `package.json` through `NEXT_PUBLIC_APP_VERSION` (set in `next.config.js`).
