# MITI v3.1.1 — Cleanup

A maintenance release with no change in behavior: it removes code, assets and dependencies nothing uses.

## Removed

- **Components and hooks** no part of the app imports: `LayoutConfig`, `TopicDataDisplay`, `PointCloudRenderer`, `ViewerControls` and `useUrdfConfig`.
- **Styles** used only by those components: the `dashboard` and `layout-config` style modules, and the unused groups in `visualization.styles.ts` and `topic.styles.ts`.
- **`public/icon.png`**, left over from the Electron build.
- **Dependencies** `zustand`, `clsx` and `@jest/globals`. Both `package-lock.json` and `bun.lock` are updated.

The docs (`README.md`, `docs/API.md`, `docs/ARCHITECTURE.md`) no longer mention the removed pieces.
