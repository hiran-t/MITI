# MITI v2.0.0 — ROS 2 Engineering Workspace

MITI 2.0 introduces a dark monitoring workspace, a shared left sidebar, immediate widget settings, and a substantially expanded ROS 2 3D scene.

## Breaking change

MITI is now a web application. Electron integration, desktop packaging, and the desktop release workflow have been removed. This release does not include desktop installers. Run with Node.js using `npm ci`, `npm run build`, and `npm start`, or use the existing container deployment workflow.

## Workspace and widgets

- Dark MITI workspace with compact panel headers, Lucide icons, and connection controls.
- Unified left sidebar with Panel, Topics, Problems, and Sources tabs.
- Settings for the selected widget only, searchable collapsible sections, and immediate updates without Apply buttons.
- Add, remove, lock, drag, resize, and maximize panels; Escape restores the workspace.
- Responsive mobile drawer and stacked panels without overwriting desktop positions.
- Existing layouts and widget topics are preserved, with hydration-safe localStorage persistence and confirmed layout reset.

## ROS 2 3D scene

- Visualize data without loading a URDF first.
- Configurable fixed frame, robot root frame, static TF topics, and timestamp-aware transforms.
- Layers for PointCloud2, LaserScan, Marker/MarkerArray, OccupancyGrid, Path, Odometry, PoseStamped, PoseArray, and CameraInfo with optional images.
- URDF models and JointState animation remain supported; URL changes load automatically after a short pause.
- Per-layer visibility, applicable display settings, and waiting, empty, stale, and error status.
- TF history/interpolation, static transform retention, and isolated subscription cleanup across widgets.
- PointCloud2 fixes for Base64 data, row padding, endianness, and packed RGB colors.
- Marker namespace/id updates, deletion, lifetime, frame locking, and common mesh formats.

## Validation

- Type checking and production build passed.
- 27 tests passed.
- Lint passed with the existing live-camera `<img>` advisory.
- Browser checks covered desktop/mobile layouts and a local WebSocket fixture with all ten layer types, URDF/joints, marker shapes and mesh loading, missing transforms, topic changes, stale data, and persistence.

## Known limits

Real rosbridge/hardware and high-density sensor throughput have not yet been validated. Camera images must be rectified and match CameraInfo. Embedded marker mesh/texture payloads, textured triangle lists, odometry covariance visualization, and simulation-clock-based marker lifetime are not implemented. This release does not claim complete RViz parity.

See [3D Scene documentation](https://github.com/hiran-t/MITI/blob/v2.0.0/docs/3d-scene.md) for supported interfaces, transform behavior, data limits, and configuration.
