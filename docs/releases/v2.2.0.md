# MITI v2.2.0 — Foxglove-style layout, Log panel and per-topic 3D settings

MITI 2.2 tiles panels the way Foxglove does, adds a Log panel for `/rosout`, and gives every topic in the 3D Scene the display settings Foxglove's 3D panel has.

## Layout

- **Panels tile the workspace instead of sitting in a block grid** (react-mosaic, as in Foxglove).
  - Drag a panel's header onto another panel; the highlighted half shows where it will go, and the panel is split there.
  - Drag the dividers between panels to resize them.
  - New panels open beside the selected panel.
  - Layouts saved by earlier versions are converted automatically and keep their arrangement.
- **Resizable sidebar**: drag its right edge to resize it; double-click the edge to reset. The width is remembered.

## Log panel

- Streams `/rosout`: `rcl_interfaces/msg/Log`, ROS 1 `rosgraph_msgs/Log` and `foxglove.Log`.
- Filtering:
  - minimum level
  - search chips that match node names or message text
  - per-node visibility
- Display options: font size, level, date, time, time zone, node name and source location.
- Copy, clear, and follow the newest message.

## 3D Scene: per-topic settings like Foxglove

- **Point clouds and laser scans**
  - Point size in pixels; circle or square points.
  - Decay time.
  - Color modes:
    - Flat
    - Color map (Turbo or Rainbow)
    - Gradient
    - RGB and RGBA
  - Color map and gradient can use any field of the message, over an automatic or fixed value range.
  - Stixel view.
  - Coloring is chosen automatically, as in Foxglove: the message's own colors, else intensity on a color map, else flat.
- **Occupancy grids and costmaps**
  - Palettes: Custom (min, max, unknown and invalid colors), Map, Costmap and Raw.
  - Frame lock and draw behind.
- **Poses, poses with covariance, pose arrays, odometry and paths**
  - Shown as axes, arrows (shaft and head dimensions), or a gradient line with width in meters.
  - Poses with covariance (e.g. `/amcl_pose`, a new layer type) and odometry draw a covariance ellipsoid.
- **Robot description**
  - Control mode: Joint states or Manual.
  - A Joint states section with live positions, or sliders in Manual mode.
  - A Links section with per-link visibility.
  - Opacity, mesh outlines and link axes.
- **Markers**: namespaces with visibility toggles.
- Color fields accept typed hex values, including `#rrggbbaa`.

## Changes to note

- Point cloud and laser scan point size is in screen pixels; sizes set in meters no longer apply.
- Poses default to axes, pose arrays and odometry to arrows, and paths to a line, as in Foxglove.
- The old arrow size setting is replaced by axis scale and arrow dimensions.
- `react-grid-layout` is replaced by `react-mosaic-component`.
